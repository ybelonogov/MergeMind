# Черновик отчета по НИР

Основной файл: `main.tex`.

Дополнительный черновик статьи: `article_draft.tex`.

Рекомендуемая сборка:

```bash
latexmk -lualatex main.tex
```

Если `latexmk` не установлен:

```bash
lualatex main.tex
lualatex main.tex
```

Перед сдачей нужно заменить плейсхолдеры в преамбуле `main.tex`:

- `<ФИО студента>`;
- `<номер группы>`;
- `<ФИО, должность руководителя>`;
- `<факультет/институт>`;
- `<образовательная программа>`.

Черновик ориентирован на структуру отчета по НИР: титульный лист, реферат,
содержание, сокращения, введение, основная часть, заключение, источники и
приложения.

`article_draft.tex` ориентирован на более короткую статью: введение, обзор
литературы, постановка задачи, подход, экспериментальная схема, начальные
результаты и дальнейшая работа.
